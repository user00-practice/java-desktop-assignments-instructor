## 準備：クローンして開く

1. IntelliJ IDEA を起動する
2. ようこそ画面の「VCS から取得」を押す（プロジェクトを開いている場合は、メニューの「ファイル」→「新規」→「バージョン管理からのプロジェクト...」）
3. 「URL」欄に、講師から伝えられたリポジトリのURLを貼り付けて「クローン」を押す
4. 「このプロジェクトを信頼しますか？」と聞かれたら「プロジェクトを信頼」を押す

課題で使っているプロジェクトとは別のプロジェクトとして開きます（パッケージ名・クラス名が同じため）。

JDKが設定されていないと表示された場合は、メニュー「ファイル」→「プロジェクト構造...」→「プロジェクト」で、バージョン25のJDKを選んでください。

## 仕様の解釈で決めたこと

- テーマ1：テストでコンピュータの手を固定できるよう、`JankenGame` に `Random` を渡せるコンストラクタを用意しています
- テーマ3：「1 ＋ 2 × 3 ＝」は仕様どおり左から順に計算して9にしています
- テーマ7：文字数は改行を除いて数えています
- テーマ8：決着後は空きマスだけを押せなくしています。印のあるマスまで無効にすると、文字が灰色になって見にくいためです
- テーマ9：メモの中のカンマは、CSVが崩れないよう「、」に置き換えて保存しています
- テーマ10：ドラッグせずにクリックしただけのときは、図形を追加しません
